# audio_decoder

Turns a file or a network stream into `AudioBatch`es for the engine. The lib root is
`decoder.rs`; everything lives in that one file.

## Responsibilities

- `Decoder` picks a backend by extension: Monkey's Audio (`ape-decoder`), DSF/DFF
  (`dsd`, decimated to PCM), or Symphonia for everything else.
- `Decoder::open_stream` decodes from a `MediaStream` (`Read + Seek`) instead of a
  `File`. `can_stream` lists the formats that must stay file-backed (ape, dsf, dff).
- Planar → interleaved conversion and mapping to `AudioSamples` (S16/S24/S32/F32).
- `Decoder::codec` names the codec (from Symphonia's codec id, or APE/DSD by
  backend). `cast` uses it to decide what a network receiver can play as it
  is: an `.m4a` may be AAC or ALAC.

## Symphonia backend

- The codec registry is our own (`CODECS`), not `symphonia::default::get_codecs()`:
  Symphonia has no Opus decoder, so `symphonia-adapter-libopus` is registered next
  to the default codecs. Do not "simplify" back to `get_codecs()` — Opus would stop
  playing and no other codec's test would notice. The adapter builds libopus from
  source through `cmake` (`opusic-sys`, bundled and statically linked), so every
  platform that compiles the app needs `cmake` on `PATH`.
- Seeking clamps the target to the track's `start_ts`. Files whose container timeline
  starts late (for example Opus muxed by ffmpeg from a video, `start_ts` = 624) reject
  a seek to 0 as out of range otherwise.
- `seek` calls `AudioDecoder::reset` for every codec except Opus.
- `exact_frames` / `seek_frame` (on `AudioSource`, default: none) are for
  `audio_embedding`, which decodes only some windows of a track. They exist only for
  FLAC, PCM (WAV/AIFF) and ALAC whose time base is `1/rate`, whose track starts at 0
  and whose **first packet** has timestamp 0 — read when the file opens and kept in
  `pending`, so playback still decodes it first. The last check matters: Symphonia
  reports `start_ts` 0 for every FLAC, but a FLAC cut with `ffmpeg -ss … -c copy`
  keeps its frame numbers (the first one is not 0) and the STREAMINFO length of the
  whole file; a CAF with priming starts at a negative timestamp. For the rest a
  packet's timestamp is its first frame and decoding after a seek is bit-identical
  to decoding through, so `seek_frame` (`SeekMode::Accurate` to a `Timestamp`)
  returns the frame it really landed on and the caller skips the rest. It lands at
  or before the target except where FLAC's search overshoots (a frame number that
  is not where the bisection expects it); the caller checks and falls back. `exact_frames` is the container's frame count (FLAC
  STREAMINFO, the WAV data size, the MP4 sample table). Symphonia's MP4 reader cannot
  seek once it read to the end of the file (`isomp4: no atom pending read`); a
  fresh reader seeks exactly.

## Opus

- Always decoded to 48 kHz F32; `bits_per_sample` is unknown, so the 16-bit fallback
  used for every lossy codec applies. Only mono and stereo (channel mapping family 0)
  are supported by the adapter; 5.1/7.1 files are indexed but fail on play with
  "unsupported number of channels".
- The adapter trims the encoder pre-skip once, on the first packet it decodes, and
  `reset` does not re-arm it. So a seek builds a fresh decoder instead of resetting.
- Opus needs history to decode correctly. A seek lands `OPUS_PREROLL_MS` before the
  target, decodes and drops the packets up to the target (`discard_before`) and keeps
  the first packet it must play in `pending`. 80 ms is the spec minimum; a dense
  high-bitrate file was still off by 6–8% in the first 20 ms at 80 ms and became
  bit-exact at 320 ms, which costs about sixteen packets per seek.
- The OpusHead output gain (Q7.8 dB) is mandatory for players and libopus does not
  apply it, so `opus_output_gain` reads it from the codec extra data and scales the
  decoded samples. This is unrelated to ReplayGain / R128 tags, which are not applied.
- The position returned by `seek` is the timestamp of the first packet that will be
  played, in the stream's own timeline: it carries the container `start_ts` and the
  pre-skip, at most a few tens of milliseconds, and is clamped at 0.

## Tests

- Fixtures are generated by `make generate` (`tagged_opus.opus`, `late_start_opus.opus`
  need an ffmpeg with `libopus`). `late_start_opus.opus` uses a sweep plus noise so a
  cold decoder state is visible, and `-output_ts_offset` to get a late timeline.
- `opus_seek_matches_a_straight_decode` compares post-seek samples with a straight
  decode, `opus_replays_identically_when_its_timeline_starts_late` guards the pre-skip
  re-arm and the `start_ts` clamp, `opus_applies_the_header_output_gain` patches the
  OpusHead gain (and the Ogg page CRC) in memory.
- Every test that decodes Opus is `#[cfg_attr(miri, ignore)]`: libopus is C, miri
  cannot call it and aborts the whole test binary. The crate stays in `MIRI_CRATES`
  for the rest of its tests.
